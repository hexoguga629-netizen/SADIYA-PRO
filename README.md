# PHANTOM NEXUS / MAX

A premium, responsive visual concept for the MAX personal AI operating system.

## UI design phase

This phase intentionally contains **only visual UI/UX**:

- Cinematic MAX Core digital-planet home screen with orbital capability nodes.
- Glass navigation, sidebar, bottom bar, command bar, quick actions, visual voice states, and polished empty states.
- UI-only views for agents, tasks, system, settings, provider configuration, vision, files, automations, devices, and accessibility.

No AI calls, voice processing, API keys, device controls, accessibility services, camera access, file access, automation engine, or live-data integrations are implemented in this phase.

## Run

```bash
npm install --legacy-peer-deps
npm run dev
```
